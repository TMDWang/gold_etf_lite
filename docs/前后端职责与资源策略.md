# 前后端职责与资源策略

## 前端

前端负责页面布局、表单输入、图表绘制和结果展示，以及基础输入提示。买入预览的最终金额由后端计算，前端不自行修改账本。买入预览打开期间，等待中的页面更新会推迟到表单关闭后；模拟输入和结果只在当前页面内存中，不写入离线缓存，页面意外重载后需重新填写。

前端在当前标签页内短暂复用成功的接口结果：账户最多 15 秒，行情和计划提醒最多 20 秒，计划、记录及行情规则最多 60 秒。处于前台时约每 30 秒检查当前页面需要的数据；切换页面、回到前台或联网后也会检查。账本和计划变更后，中止旧的未完成请求并强制更新当前页面，其他页面下次访问时重新获取；单条提醒设置会刷新相应区域。网络请求失败时保留已显示数据并提示，不把旧数据当成新请求成功。退出或登录失效时清除页面内个人数据及复用状态。

## 后端

后端负责登录与权限校验、账号数据隔离、定点金额计算、账本和纠错、计划与提醒规则、行情采集和数据校验、定时监测及 PushPlus 推送。所有写入以服务端校验为准；买入预览只读取当前账户并计算，不写入账本。

账户接口返回最新参考价及源时间，用于持仓页及预览。持仓页无需下载完整分时曲线；首页才请求曲线。系统不因缓存而忽略行情有效性，提醒仍由后端在有效交易时段依据有效行情检查。

## 静态与动态资源

- 页面外壳、版本化的 CSS、入口脚本和图标属于公共静态资源，由 Service Worker 缓存；前端代码变动生成新版本文件。
- 分时图脚本按需下载，首次需要图表时才缓存，最多保留两个版本；缓存只匹配同源的图表脚本路径。
- 所有 `/api/` 请求为动态数据，服务端返回 `Cache-Control: no-store, private`；Service Worker 不缓存 API 响应。当前页内复用是内存状态，不是设备离线存储。
- 实际节省量取决于用户访问页面和行情数据量；静态资源首次下载、版本更新、缓存被系统清理或网络连接本身仍需流量。
