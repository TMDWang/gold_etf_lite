## 实施取舍与未能判断的项目

- 本目录不是 Git 仓库，以独立应用子目录和压缩包保存；代价是没有 Git 提交回退记录。
- 用户“先做出来吧”按详细草案的推荐会话、账号恢复和参数默认值执行；后续可在成品基础上调整。
- 账本按记账顺序计算，纠错在原笔位置重算；代价是补录更早成交需要自己按顺序核对。界面和部署说明已提示。
- 免费行情用 requests 读取东财／新浪窄接口，日历复用 exchange-calendars；代价是上游字段变化需维护适配器。
- Vite 使用 native 配置加载器以适配受限 Windows 路径；对 NAS 的业务功能无变化。
- 有已有持仓时要求核对并录入正成本，防止把未知期初成本当成零后与后续买入混合计算虚假盈利；代价是成本不清楚时须先到券商核对，不能先填零跳过。
- 无 Docker daemon／PostgreSQL 服务，无法判断真实容器启动、NAS 架构及行锁结果；交付明确保留 NAS 验收项，不把 SQLite 结果当作这些项目的证明。
- 盘后探测不能判断盘中时效；模拟推送不能判断真实微信送达。这两项应由本人在部署后验证，不代亲友发送测试。
- Supervisor 权限风险已采用逐进程降权规避，仍需容器实测；关于二次纠错的怀疑已撤回，不保留为缺陷。
